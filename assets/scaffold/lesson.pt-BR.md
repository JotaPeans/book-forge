Ao final você será capaz de:
- Verbo + resultado verificável (3 a 5 itens)

## O problema, antes da solução

Conceito + analogia com algo que o leitor já conhece (ponte com as linguagens que ele usa).

::: conceito a ideia central
Definição curta. É o que vale memorizar.
:::

## Exemplo comentado

```python run
print("exemplo mínimo que roda")
```

```saida
```

::: pausa 1 minuto
Pergunta que o leitor responde ANTES de seguir. Prever a saída de um código é uma boa pausa.
:::

## O que dá errado

```python fail
print(variavel_inexistente)
```

```erro
```

::: erro-comum
A armadilha em que quase todo iniciante cai, e como sair dela.
:::

## Para que serve na prática

::: pratica
Onde isto aparece em programas reais.
:::

::: dica
Um macete mental.
:::

::: exercicios
1. Fácil: aplicar o exemplo com outros valores.
2. Fácil: prever e depois conferir uma saída.
3. Médio: combinar com a aula anterior.
4. Desafio: variação que exige pensar.
:::

::: resumo
- Três a cinco frases que o leitor deveria saber repetir.
:::

::: gabarito
**1.** Resposta completa, com a explicação do porquê.

**2.** Outra resposta, explicada.
:::
